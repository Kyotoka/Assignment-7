# বাজার দর (BazarDor)

বাজার দর হলো নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজার দর ট্র্যাকিং ওয়েবসাইট।

## প্রযুক্তিসমূহ (Technologies Used)

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- BetterAuth
- React Hot Toast
- Lucide React

## ৫টি প্রধান বৈশিষ্ট্য (5 Key Features)

1. **লাইভ প্রাইস ট্র্যাকার (Ticker):** স্ক্রলিং টিকেটের মাধ্যমে রিয়েল-টাইম দর বৃদ্ধি ও হ্রাসের তথ্য।
2. **ক্যাটাগরি অনুযায়ী ফিল্টারিং:** চাল, সবজি সহ বিভিন্ন ক্যাটাগরির পণ্য সহজে নির্বাচন।
3. **পণ্য সারসংক্ষেপ ও ডিটেইলস (Protected Route):** প্রতি পণ্যের সর্বনিম্ন, সর্বোচ্চ ও গড় দাম পর্যবেক্ষণ।
4. **বাংলা সর্টিং সহ ক্যাটাগরি পেজ:** কম থেকে বেশি বা বেশি থেকে কম দামে সর্ট করার সুবিধা।
5. **ইউজার অথেনটিকেশন ও প্রোফাইল আপডেট:** BetterAuth দিয়ে লগইন, রেজিস্ট্রেশন ও নাম পরিবর্তনের সুবিধা।
