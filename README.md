# 🛒 বাজার দর (BazarDor)
> *“আলু নাকি পটল? ডিমের দাম বাড়ছে নাকি কমছে? সব খবর এখন আপনার হাতের মুঠোয়!”*

**বাজার দর** হলো নিত্যপ্রয়োজনীয় পণ্যের দরদাম ট্র্যাক করার একটি আধুনিক, ফাস্ট এবং ইউজার-ফ্রেন্ডলি ওয়েবসাইট। বাজারে গিয়ে দরদাম নিয়ে বিভ্রান্ত হওয়ার দিন শেষ!

---

## ⚡ প্রযুক্তিসমূহ (Tech Stack)

আমাদের প্রজেক্টটি তৈরি করতে যে সমস্ত সুপার-পাওয়ার ব্যবহার করা হয়েছে:

| প্রযুক্তি | ব্যবহার |
| :--- | :--- |
| **Next.js (App Router)** | রকেট স্পিড সার্ভার-সাইড রেন্ডারিং এবং আধুনিক রাউটিং |
| **React & TypeScript** | বাগ-ফ্রি স্মুথ ইউআই এবং মজবুত কোডবেস |
| **Tailwind CSS** | আই-ক্যান্ডি, রেসপন্সিভ এবং ক্লিন ডিজাইন |
| **BetterAuth** | বুলেটপ্রুফ অ্যান্ড সুপার-ফাস্ট ইউজার অথেনটিকেশন |
| **Lucide React & React Hot Toast** | চমৎকার আইকন এবং ঝকঝকে নোটিফিকেশন অ্যালার্ট |

---

## 🌟 ৫টি জাদুকরী বৈশিষ্ট্য (5 Key Features)

* **📢 লাইভ প্রাইস টিকেটিং:** শেয়ার বাজারের মতো স্ক্রলিং টিকারে মুহূর্তেই দেখে নিন কোন পণ্যের দাম উর্ধ্বমুখী 📈 আর কোনটা নিম্নমুখী 📉।
* **🔍 স্মার্ট ক্যাটাগরি ফিল্টার:** চাল, ডাল, তেল কিংবা শাকসবজি—যা চান তা নিমেষেই এক ক্লিকে খুঁজে নিন।
* **📊 ইন-ডেপথ প্রোডাক্ট ডিটেইলস (Protected):** কোনটা কেনাকাটায় লাভ? সর্বনিম্ন, সর্বোচ্চ এবং গড় দামের নিখুঁত হিসাব দেখে বুদ্ধিমান ক্রেতা হয়ে যান!
* **🔤 বাংলা ফ্রেন্ডলি সর্টিং:** কম দাম থেকে বেশি, নাকি বেশি থেকে কম? বাংলা ইন্টারফেসেই সর্ট করুন চোখের পলকে।
* **👤 ইউজার প্রোফাইল ও অথেনটিকেশন:** `BetterAuth`-এর পাওয়ারে চটপট সাইন-ইন করুন, নিজের প্রোফাইল সাজান আর নাম আপডেট করে নিন যখন খুশি।
